# Web Scraping Product Data using Python

This project demonstrates the use of web scraping techniques to extract structured data from a website using Python. The scraper collects product-related information such as product name, price, and rating from multiple pages and stores it in a CSV file for further use.

The project uses libraries like Requests to fetch webpage content, BeautifulSoup to parse HTML, and Pandas to organize and store the extracted data. It also includes basic data cleaning steps such as formatting price values and structuring the dataset for analysis.

## Key Features

* Multi-page web scraping
* Extraction of product details (name, price, rating)
* Data cleaning and transformation
* Exporting data to CSV format

## Technologies Used

* Python
* Requestsck
* BeautifulSoup
* Pandas

## Output

A structured dataset (`products_data.csv`) containing product details that can be used for further analysis or visualization.
